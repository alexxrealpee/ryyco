# Carpeta de APIs

Esta carpeta está ubicada en `/public/api/apis` para almacenar APIs, recursos JSON o endpoints estáticos accesibles directamente por la aplicación o servicios externos en la ruta:

`https://<tu-dominio>/api/apis/<archivo>`

### Ejemplos de uso:
- `/public/api/apis/status.json` -> Accesible en `/api/apis/status.json`
- `/public/api/apis/endpoints.json` -> Especificación de endpoints o integraciones
